How to run the Men Salon Management System Using PHP and MySQL

1.Download the zip file
2.Extract the file and copy russell folder.
3.Paste inside root directory(for xampp xampp/htdocs, for wamp wamp/www, for lamp var/www/html)
4.Open PHPMyAdmin (http://localhost/phpmyadmin)
5.Create a database with name lumineuxdb ( you may use desired database name)
6.Import lumineuxdb.sql file(given inside the zip package in DATABASE file folder)
7.Run the script http://localhost/russell
